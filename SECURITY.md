# Security policy

## Supported version

Security fixes are made on the current default branch. This project does not
promise support for older commits, forks, or deployments.

## Reporting a vulnerability

Do not open a public issue containing a vulnerability, credential, member data,
or production infrastructure detail. Use **Security → Advisories → Report a
vulnerability** in this repository. If GitHub does not show that route, contact
repository owner [@mgarvey](https://github.com/mgarvey) privately through their
GitHub profile without including sensitive details in a public post. Include
only the minimum information needed to reproduce the concern. Do not access,
copy, or alter real member data while testing.

The maintainer will acknowledge the report, establish a private coordination
channel, and separate source changes from any credential rotation, hosted
configuration, deployment, or data-repair decision.

## Deployment responsibility

This repository is provided under the MIT License and is not a managed service.
Each deploying community is responsible for its own privacy review, access
controls, provider accounts, backups, monitoring, incident response, and legal
or organizational requirements.
